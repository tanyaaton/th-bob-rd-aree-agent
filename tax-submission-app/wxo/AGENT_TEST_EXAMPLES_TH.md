# ตัวอย่างการทดสอบเอเจนต์

เอกสารนี้แสดงตัวอย่างการสนทนาเพื่อทดสอบการเชื่อมต่อของเอเจนต์ยื่นภาษีกับ API

**ข้อกำหนดเบื้องต้น:**
- Tax Submission API ต้องทำงานอยู่ที่ `http://localhost:8080`
- เอเจนต์ต้องถูกกำหนดค่าด้วยเครื่องมือทั้งสาม: `validateUser`, `submitTax`, `getSubmissionHistory`
- เลขบัตรประชาชนที่ใช้ทดสอบได้: `1234567890123`

---

## กรณีทดสอบที่ 1: ตรวจสอบตัวตนผู้ใช้

### ข้อความจากผู้ใช้:
```
ฉันต้องการตรวจสอบตัวตนด้วยเลขบัตรประชาชน 1234567890123
```

### พฤติกรรมที่คาดหวังจากเอเจนต์:
1. เอเจนต์เรียกใช้เครื่องมือ `validateUser` ด้วย:
   ```json
   {
     "national_id": "1234567890123"
   }
   ```
2. API ส่งคืนการตอบกลับที่สำเร็จพร้อมรายละเอียดผู้ใช้
3. เอเจนต์ยืนยันการตรวจสอบและแสดงข้อมูลผู้ใช้

### การตอบกลับที่คาดหวัง:
```
การตรวจสอบตัวตนของคุณสำเร็จแล้ว!

รายละเอียดผู้ใช้:
- ชื่อ: John Doe
- วันเกิด: 1990-01-01
- เลขบัตรประชาชน: 1234567890123

ตอนนี้คุณสามารถดำเนินการยื่นแบบภาษีได้แล้ว
```

### การทดสอบทางเลือก (ผู้ใช้ไม่ถูกต้อง):
```
ช่วยตรวจสอบเลขบัตรประชาชน 9999999999999 ให้หน่อย
```

ผลที่คาดหวัง: เอเจนต์ควรรายงานว่าไม่พบผู้ใช้หรือไม่ได้รับอนุญาต

---

## กรณีทดสอบที่ 2: ยื่นแบบภาษี (แบบง่าย)

### ข้อความจากผู้ใช้:
```
ฉันต้องการยื่นแบบภาษี มีรายได้จากเงินเดือน 50000 บาท
```

### พฤติกรรมที่คาดหวังจากเอเจนต์:
1. เอเจนต์เรียกใช้เครื่องมือ `submitTax` ด้วย:
   ```json
   {
     "name": "John Doe",
     "national_id": "1234567890123",
     "income_data": [
       {
         "type": 1,
         "amount": 50000,
         "details": "รายได้จากเงินเดือน"
       }
     ]
   }
   ```
2. API ส่งคืนความสำเร็จพร้อมหมายเลขการยื่น
3. เอเจนต์ยืนยันการยื่น

### การตอบกลับที่คาดหวัง:
```
ยื่นแบบภาษีของคุณสำเร็จแล้ว!

รายละเอียดการยื่น:
- หมายเลขการยื่น: 1
- ชื่อ: John Doe
- เลขบัตรประชาชน: 1234567890123
- รายได้รวม: 50,000 บาท

รายละเอียดรายได้:
1. เงินเดือน/รายได้จากการจ้างงาน (ประเภท 1): 50,000 บาท

การยื่นของคุณได้รับการบันทึกแล้ว
```

---

## กรณีทดสอบที่ 3: ยื่นแบบภาษี (หลายประเภทรายได้)

### ข้อความจากผู้ใช้:
```
ยื่นแบบภาษีของฉัน:
- ชื่อ: John Doe
- เลขบัตรประชาชน: 1234567890123
- เงินเดือน: 50000 บาท
- รายได้ฟรีแลนซ์: 15000 บาท
- รายได้จากการลงทุน: 12000 บาท
```

### พฤติกรรมที่คาดหวังจากเอเจนต์:
1. เอเจนต์เรียกใช้เครื่องมือ `submitTax` ด้วย:
   ```json
   {
     "name": "John Doe",
     "national_id": "1234567890123",
     "income_data": [
       {
         "type": 1,
         "amount": 50000,
         "details": "เงินเดือน"
       },
       {
         "type": 3,
         "amount": 15000,
         "details": "รายได้ฟรีแลนซ์"
       },
       {
         "type": 10,
         "amount": 12000,
         "details": "รายได้จากการลงทุน"
       }
     ]
   }
   ```
2. API ส่งคืนความสำเร็จ
3. เอเจนต์ยืนยันพร้อมรายละเอียด

### การตอบกลับที่คาดหวัง:
```
ยื่นแบบภาษีของคุณสำเร็จแล้ว!

รายละเอียดการยื่น:
- หมายเลขการยื่น: 2
- ชื่อ: John Doe
- เลขบัตรประชาชน: 1234567890123
- รายได้รวม: 77,000 บาท

รายละเอียดรายได้:
1. เงินเดือน/รายได้จากการจ้างงาน (ประเภท 1): 50,000 บาท
2. ฟรีแลนซ์/งานสัญญาจ้าง (ประเภท 3): 15,000 บาท
3. ดอกเบี้ย/เงินปันผล (ประเภท 10): 12,000 บาท

การยื่นของคุณได้รับการบันทึกแล้ว
```

---

## กรณีทดสอบที่ 4: ดึงประวัติการยื่นภาษี

### ข้อความจากผู้ใช้:
```
แสดงประวัติการยื่นภาษีของฉัน
```

### พฤติกรรมที่คาดหวังจากเอเจนต์:
1. เอเจนต์เรียกใช้เครื่องมือ `getSubmissionHistory` (ไม่ต้องใช้พารามิเตอร์)
2. API ส่งคืนรายการการยื่นทั้งหมด
3. เอเจนต์จัดรูปแบบและแสดงประวัติ

### การตอบกลับที่คาดหวัง:
```
นี่คือประวัติการยื่นภาษีของคุณ:

การยื่นครั้งที่ 1:
- วันที่ยื่น: 2026-05-08 12:00:00
- ชื่อ: John Doe
- เลขบัตรประชาชน: 1234567890123
- รายได้รวม: 50,000 บาท
- ประเภทรายได้: 1 (เงินเดือน)

การยื่นครั้งที่ 2:
- วันที่ยื่น: 2026-05-08 12:15:00
- ชื่อ: John Doe
- เลขบัตรประชาชน: 1234567890123
- รายได้รวม: 77,000 บาท
- ประเภทรายได้: 1 (เงินเดือน), 3 (ฟรีแลนซ์), 10 (การลงทุน)

จำนวนการยื่นทั้งหมด: 2
```

### คำถามทางเลือก:
```
การยื่นภาษีครั้งก่อนของฉันมีอะไรบ้าง?
```
```
ช่วยดึงประวัติการยื่นของฉันให้หน่อย
```
```
แสดงรายการแบบภาษีทั้งหมดของฉัน
```

---

## กรณีทดสอบที่ 5: ขั้นตอนการทำงานแบบสมบูรณ์

### ข้อความจากผู้ใช้ (ตามลำดับ):
```
1. ก่อนอื่นตรวจสอบตัวตนของฉัน: 1234567890123
```
```
2. ตอนนี้ยื่นภาษีของฉันด้วยเงินเดือน 60000 และรายได้จากค่าเช่า 20000
```
```
3. แสดงประวัติการยื่นให้ฉันดู
```

### ขั้นตอนที่คาดหวัง:
1. **ขั้นตอนที่ 1**: เอเจนต์ตรวจสอบผู้ใช้ → สำเร็จ
2. **ขั้นตอนที่ 2**: เอเจนต์ยื่นภาษีด้วยประเภท 1 (เงินเดือน) และ 5 (ค่าเช่า) → สำเร็จพร้อมหมายเลขการยื่น
3. **ขั้นตอนที่ 3**: เอเจนต์ดึงประวัติ → แสดงการยื่นทั้งหมดรวมถึงรายการใหม่

---

## กรณีทดสอบที่ 6: การจัดการข้อผิดพลาด

### เลขบัตรประชาชนไม่ถูกต้อง:
```
ตรวจสอบเลขบัตรประชาชน 0000000000000
```
ผลที่คาดหวัง: เอเจนต์รายงานว่าไม่ได้รับอนุญาตหรือไม่พบผู้ใช้

### ข้อมูลไม่ครบ:
```
ยื่นแบบภาษีของฉัน
```
ผลที่คาดหวัง: เอเจนต์ถามข้อมูลที่จำเป็น (ชื่อ, เลขบัตรประชาชน, ข้อมูลรายได้)

### ประเภทรายได้ไม่ถูกต้อง:
```
ยื่นภาษีสำหรับ John Doe เลขบัตร 1234567890123 ด้วยประเภทรายได้ 99 จำนวน 50000
```
ผลที่คาดหวัง: เอเจนต์รายงานว่าประเภทรายได้ไม่ถูกต้อง (ต้องเป็น 1-17)

| 11 | เงินปันผลจากหุ้น | 8,000 บาท |

## คำสั่งทดสอบแบบรวดเร็ว

### การทดสอบแบบย่อ:
```
ตรวจสอบเลขบัตร 1234567890123 แล้วยื่นภาษีสำหรับ John Doe ด้วยเงินเดือน 50000 แล้วแสดงประวัติ
```

### การทดสอบแบบครบถ้วน:
```
ฉันชื่อ John Doe เลขบัตรประชาชน 1234567890123 ต้องการยื่นภาษีด้วย:
- เงินเดือน: 50000
- ฟรีแลนซ์: 15000
- ค่าเช่า: 20000
- การลงทุน: 12000
แล้วแสดงประวัติการยื่นของฉัน
```

## การแก้ไขปัญหา

หากเอเจนต์ไม่สามารถเชื่อมต่อกับ API:

1. **ตรวจสอบว่า API กำลังทำงาน:**
   ```bash
   curl http://localhost:8080/api/history
   ```

2. **ตรวจสอบว่าเครื่องมือของเอเจนต์ถูกกำหนดค่า:**
   - validateUser
   - submitTax
   - getSubmissionHistory

3. **ตรวจสอบ API endpoint ในการกำหนดค่าเอเจนต์:**
   - ควรชี้ไปที่ `http://localhost:8080`

4. **ทดสอบ endpoint แต่ละตัว:**
   ```bash
   # ตรวจสอบ
   curl -X POST http://localhost:8080/api/validate-user \
     -H "Content-Type: application/json" \
     -d '{"national_id": "1234567890123"}'
   
   # ยื่น
   curl -X POST http://localhost:8080/api/submit-tax \
     -H "Content-Type: application/json" \
     -d '{"name": "John Doe", "national_id": "1234567890123", "income_data": [{"type": 1, "amount": 50000}]}'
   
   # ประวัติ
   curl http://localhost:8080/api/history
   ```

## หมายเหตุ

- การทดสอบทั้งหมดใช้เลขบัตรประชาชนที่ถูกต้อง: `1234567890123`
- API จะยอมรับเฉพาะเลขบัตรประชาชนนี้สำหรับการตรวจสอบและการยื่น
- ประเภทรายได้ต้องอยู่ระหว่าง 1-17
- จำนวนเงินต้องเป็นตัวเลขที่ไม่เป็นลบ
- ต้องมีรายการรายได้อย่างน้อยหนึ่งรายการสำหรับการยื่นภาษี
